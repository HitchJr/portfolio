    I'm not a software engineer. I'm an operations lead who learns systems fast and uses AI to build tools people actually use. Here's exactly where my skills end and the AI's begin.

    On my own

    • Fix and adapt the VBA macros in the tools my team uses every day
    • Plan what a tool needs to do, for whom, and what's out of scope
    • Test the result against how it should work, and send it back when it doesn't

    With AI Claude and Claude Code

    • Build web apps in Next.js, React and TypeScript by directing Claude Code

    • Put projects on GitHub and live on Vercel, like this site

    How a build runs

    1. 1Scope What problem, for whom, and what it won't do.
    2. 2Plan Structure and data before any code.
    3. 3Build Claude Code writes, I direct.
    4. 4Check Every result tested. Rail work taught me not to assume.
    5. 5Ship Live, then improved from real use.
