The idea

A lot of web fiction is published chapter by chapter on websites, as text only. VoiceReader collects the chapters and reads them aloud, so you can listen on your phone instead of reading.

What I built

  • Site scrapers that fetch new chapters from the websites.
  • Sentence segmentation, so text is read and tracked one sentence at a time.
  • API routes and a database behind the app.
  • A player with a waveform scrubber that highlights each sentence as it’s read.

How I worked

I planned the scope and architecture first, then directed the build with Claude Code and checked every result.
